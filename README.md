# Task Management API

A Django REST Framework backend API that allows users to manage projects and tasks efficiently.

## Features

- User registration and authentication
- Project management
- Task management
- Task status updates
- Filtering and sorting tasks
- Ownership-based permissions

## Tech Stack

- Python
- Django
- Django REST Framework
- SQLite (development)

## Project Structure

├── users/

├── task_management_api/
│
